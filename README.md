# Amigo Secreto

Aplicación simple en JavaScript que permite agregar nombres de amigos a una lista y realizar un sorteo aleatorio para elegir un "amigo secreto".

---

## Descripción del proyecto
Este proyecto es una práctica de **JavaScript DOM** que implementa las siguientes funcionalidades:
- Agregar amigos a una lista.
- Visualizar en pantalla los amigos registrados.
- Sortear un amigo secreto al azar.
- Validar entradas vacías.
- Limpiar el campo de texto después de cada inserción.

---

## Funcionalidades
- `Agregar amigo`: permite ingresar un nombre en el campo de texto.
- `Mostrar lista`: genera dinámicamente elementos `<li>` con cada amigo.
- `Sortear amigo`: selecciona un nombre aleatorio de la lista.
- Validaciones para evitar entradas vacías.

---

## Tecnologías utilizadas
- **HTML5**
- **CSS3**
- **JavaScript (DOM, Arrays, Math.random)**
